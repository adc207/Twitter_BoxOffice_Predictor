# Twitter Based Movie Revenue Predictor

This project predicts box office revenue using user ratings from Twitter-based data and compares it with real-world revenue from a Kaggle dataset.

# Files Included

- "final_twitter_boxoffice_model.ipynb" — the full Jupyter notebook with all code
- "final_twitter_boxoffice_model.ipynb.pdf" — exported version of the notebook
- "merged_movies_ratings.csv" — sentiment data from MovieTweetings, this Kaggle set: https://www.kaggle.com/datasets/tunguz/movietweetings?select=ratings.dat 
- "top_english_movies.csv" — revenue data scraped from Kaggle, this Kaggle set: https://www.kaggle.com/datasets/kalilurrahman/top-box-office-revenue-data-english-movies
- "final_report.pdf" — our written report answering all 6 questions
